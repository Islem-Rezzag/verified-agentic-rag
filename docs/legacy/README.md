# Legacy Archive

This folder stores artifacts and inputs from earlier project stages that are no
longer part of the active architecture.

- `old-eval-outputs/`: superseded one-off JSON outputs from pre-suite eval flows.
- `comparisons/`: earlier ad-hoc comparison snapshots.
- `evalset/questions.v1.jsonl`: legacy single-file evalset format used before the
  gold/silver schema split.
- `download_sample_repo.sh`: deprecated helper script (kept only for provenance).
